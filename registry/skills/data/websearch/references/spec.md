# Web Search — Definition of Done

## Success Criteria

1. Return current, accurate information
2. Include 3-5 key bullet points
3. Include relevant URLs/sources
4. Source properly cited

## Output Format

```json
{
  "query": "search terms",
  "summary": "3-5 bullet points...",
  "sources": [
    {"url": "...", "title": "..."}
  ]
}
```
