# Free asset and data libraries (checked 23 Oct 2026, BRAVE Haiku team brave-1023)

Licence notes are summaries; open the licence link before shipping a client asset. The team checked Unsplash, Pexels, Coverr, unDraw, Humaaans, Storyset, Iconify, Lucide, Kenney, Fontsource, LottieFiles, Magic UI, OWID and Hugging Face; the other rows are from general knowledge.

| Kind | Library | URL | Licence | API |
|---|---|---|---|---|
| Photos | Unsplash | https://unsplash.com | free, commercial; API apps must credit photographer + Unsplash with UTM link | yes |
| Photos/video | Pexels | https://www.pexels.com | free, commercial, no credit; no resale or ML training without permission | yes, 200/h |
| Photos | Pixabay | https://pixabay.com | free, commercial, no credit; no standalone resale | yes |
| Video | Coverr | https://coverr.co | free for ads and client work, no credit (check each clip) | yes |
| Illustrations | unDraw | https://undraw.co | free, commercial, no credit; bans AI training and scraping | no |
| Illustrations | Humaaans / Open Peeps | https://www.humaaans.com, https://www.openpeeps.com | CC0 | no |
| Illustrations | Storyset | https://storyset.com | free with attribution (Freepik terms) | no |
| Icons | Iconify (all sets) | https://iconify.design | per icon set (most MIT/Apache/ISC) | yes |
| Icons | Lucide, Tabler, Phosphor, Heroicons | https://lucide.dev, https://tabler.io/icons, https://phosphoricons.com, https://heroicons.com | ISC / MIT | npm |
| 3D and game | Kenney | https://kenney.nl/assets | CC0 | no |
| 3D | Poly Pizza | https://poly.pizza | CC0 / CC-BY per model | yes |
| 3D | Sketchfab (downloadable, CC filter) | https://sketchfab.com | per model, CC licences | yes |
| Fonts | Google Fonts / Fontsource | https://fonts.google.com, https://fontsource.org | SIL OFL mostly | yes / npm |
| Animation | LottieFiles (free) | https://lottiefiles.com | Lottie Simple License: commercial, no credit, no resale | yes |
| UI | shadcn/ui, Magic UI (free tier), Origin UI, 21st.dev | https://ui.shadcn.com, https://magicui.design, https://originui.com, https://21st.dev | MIT for shadcn and Magic UI free; check others per component | CLI |
| Gradients/patterns | Hero Patterns, Haikei, Mesh gradients | https://heropatterns.com, https://haikei.app | free, commercial | no |
| Data | Our World in Data | https://ourworldindata.org | own charts CC BY (cite); third-party data per source | yes |
| Data | Hugging Face datasets | https://huggingface.co/datasets | per dataset card licence tag | yes |
| Data | Kaggle datasets | https://www.kaggle.com/datasets | per dataset | yes |
| Data | data.gov, data.gov.uk, EU Open Data | https://data.gov, https://data.gov.uk, https://data.europa.eu | open government licences | yes |
| Data | OpenStreetMap / Overpass | https://www.openstreetmap.org | ODbL (attribute, share-alike for data) | yes |
| Code | GitHub search, awesome-lists | `gh search repos <words> --sort stars` | per repo | yes |
